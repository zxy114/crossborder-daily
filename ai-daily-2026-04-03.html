Claude Code 源码泄露事件持续发酵：恶意木马、DMCA 删除、OpenClaude 分支
热点 ✅ 多源验证 来源：The Register | Business Insider | Cybernews
核心事件：3月31日 Claude Code 源码通过 npm source map 泄露后，事件持续升级。Zscaler 发现伪装成泄露源码的恶意仓库包含 RAT 木马；Anthropic 发起 DMCA 删除 8,100+ GitHub 仓库；开发者创建 OpenClaude 分支支持多模型。
关键数据：泄露推文获得 2900 万浏览；某 GitHub 仓库获 30,000 星、40,200 fork；npm 安装受影响时间窗口：3月31日 00:21-03:29 UTC。
影响范围：AI 开发者社区安全、Anthropic 品牌声誉。
后续动作：Anthropic 撤回大部分 DMCA 通知（仅保留一个）；GitHub 恢复被误删的 fork。
解读分析：事件意义：AI 安全公司自身遭遇重大安全事故，凸显供应链安全风险。竞争格局：开源社区迅速利用泄露代码创建多模型兼容版本，可能削弱 Anthropic 的技术壁垒。风险：安装了受影响版本的用户可能已感染木马。机会：开发者可参考 Claude Code 架构改进自己的工具。

Bonsai 8B：首个商用可行的 1-bit LLM，仅需 1.15GB 内存
趋势 ✅ PrismML / Substack 来源：MarkMan Capital | ByteIota
核心事件：PrismML 3月31日发布 Bonsai 8B，首个商用级 1-bit 量化 LLM。
关键数据：8.2B 参数压缩至 1.15GB（标准 16-bit 模型的 1/14）；推理速度 8 倍提升。
影响范围：边缘计算、本地 AI 部署。
后续动作：可在 llama.cpp 和 AnythingLLM 运行，Ollama 支持待完善。
解读分析：1-bit 量化使 8B 级模型可在消费设备本地运行。如果 benchmark 表现持续验证，将推动端侧 AI 大规模普及。对云计算厂商的 LLM API 业务可能产生冲击。
