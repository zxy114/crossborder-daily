1. 美国 Section 232 药品 100% 关税正式生效：Annex III 17 家药企 7/31 起入征，9/29 全面落地

头条 贸易壁垒 Section 232 📅 2026-07-31 生效 · 来源：White House / USTR / Federal Register · Trade Compliance Hub · Zonos Tracker · Avalara 解读
📌 核心事件
根据总统公告与 Annex III 名单，Section 232 框架下针对专利品牌药品与活性药物成分（API）的 100% 从价关税于 7/31 对 17 家指定药企正式生效，剩余企业延至 9/29 全面征收。仿制药、生物类似药、孤儿药明确豁免。
📊 关键数据
标准税率 100%；欧盟/日本/韩国/瑞士-列支敦士登产：15% 减 1 栏税率（MFN≥15% 时为 0%）；英国产：10%；含获批"在岸化计划"企业：20%；MFN≥100% 项目按 100% 减 1 栏税率征收；Annex II（自贸协定企业）0% 宽限期延至 2029/1/20；仿制药/生物类似药/孤儿药豁免。
🌍 影响范围
中国跨境医药出海链条直接承压：原料药出口、保健品跨境电商、健康类 DTC 品牌（按 OTC 申报）均面临"被强制归类"风险。欧洲药企的"产能转移中国"路径被堵；中国跨境电商保健 / 营养品类（FDA 备案企业）需要在 9/29 前完成产品 HS 复核与原产地声明。
⏭️ 后续动作
1）跨境卖家立即排查涉及"专利药/品牌原料/活性成分"的 SKU 报关单；2）9/29 前完成 Annex III 名单以外的原料药 / API HS Code 复审；3）OEM/ODM 路径下切换合同主体至豁免国家（英国、韩国、瑞士）的窗口正在收窄；4）跨境医药合规服务商（CEP/FDA DMF）需求 Q3-Q4 将放量。
💡 解读分析
Section 232 药品 100% 关税是 2026 年迄今"贸易壁垒升级"最显著的单一动作，释放三层信号：1）美方把"国家安全"工具箱用到生物医药领域，跨行业辐射预期；2）"豁免名单 + 复合税率"的结构远比单一税率更难测算，企业需要做"产品-原产地-主体"三维合规；3）对跨境卖家实际意味着——所有美国仓发 / 直邮小包都可能被要求重新申报 HS 与原产地，10 位 HS Code 是新的"硬门槛"。

2. 美国 Section 122 临时全球 10% 附加费 7/24 正式到期：邮政小包首次与商业货件同税基

头条 结构性变化 邮政清关 📅 2026-07-24 生效 · 来源：Zonos / CBP / ShipperHQ · ShipperHQ · Zonos 官方
📌 核心事件
Section 122 临时 10% 全球附加费 7/24 到期，对所有邮政渠道（含境外始发）同步终止。同一时刻，CBP 将邮政包裹从"简化/均一清关"切换为与商业货件相同的标准清关——邮政渠道首次按完整 HS / 原产地 / 价值税基征税。
📊 关键数据
邮政 DDP（预付税）起征点由 $800 提至 $2,500；10 位 HS Code 强制申报（短代码将被退运）；10/22 起未提供完整数据 100% 合规要求；平均贸易加权关税由 11% 微升至 11.2%，但结构从"单一税率"转为"国别 / 品类 / HS 三维拼图"；中国平均税率升至约 27%、巴西约 18%。
🌍 影响范围
跨境小包直邮模式的核心成本结构被永久改写：1）Temu / Shein / AliExpress 的小包低价模型需重测 UE；2）邮政清关时效延长（10 位 HS 申报 + 数据核验）；3）"邮政简化清关"红利消失，海外仓前置的边际收益显著上升。
⏭️ 后续动作
1）所有跨境卖家需要在 10/22 前完成 SKU 级 HS Code / 原产地 / 申报价值数据清洗；2）DDP（预付税）展示需前置到购物车页；3）评估是否将邮政直邮 SKU 切到海外仓发货（一次性备货成本 vs 边际履约成本对比）；4）排查 USPS/UPS/FedEx 三段外包的退运风险。
💡 解读分析
Section 122 到期不是"降税"而是"换规则"——平均税率小幅上行但税基结构性重组。"邮政 = 简化"的等式被打破后，跨境电商的两个长期红利同时消失：邮政时效红利 + 申报简化红利。Q3-Q4 的"邮政直邮仓切换海外仓"是确定性趋势，Q1 2027 海外仓比例将进一步抬升。给卖家的实战建议是：HS Code 数据治理是 2026 下半年最高 ROI 的 IT 投入。

3. USTR 7/23 公告：60 国强迫劳动 Section 301 关税 7/24 起征，10-12.5% 阶梯税率

头条 全球覆盖 Section 301 📅 2026-07-23 公告 · 7/24 生效 · 来源：USTR Federal Register / Zonos / Trade Compliance Hub · Trade Compliance Hub · Zonos Tracker
📌 核心事件
美国贸易代表办公室（USTR）于 7/23 公告针对约 60 个经济体的 Section 301 强迫劳动相关新关税，7/24 零时正式生效，立即接续 Section 122 附加费的窗口结束。新税率采取"10-12.5%"两档阶梯结构。
📊 关键数据
税率档位 10% 与 12.5%；覆盖 60 个经济体（含阿尔及利亚、安哥拉、阿根廷、澳大利亚、哥斯达黎加、多米尼加、厄瓜多尔、埃及、新西兰等）；阿根廷贸易协议适用 10%；大部分交易可申请豁免；与 MFN / Section 232 / Section 301 既有税率叠加适用；与 25% Section 301 巴西关税形成"双层 Section 301"结构。
🌍 影响范围
对从墨西哥、东欧、东南亚、中东等近岸 / 友岸采购的中国卖家："近岸绕道"的边际收益被压缩；对从欧洲、日韩、澳新采购的卖家：可申请豁免通道仍开；对纯中国直邮卖家：Section 122 到期 + 邮政标准清关 + 60 国 Section 301 三重叠加，平均税率升至 27% 区间。
⏭️ 后续动作
1）跨境卖家需要做"国别税基地图"——按原产国整理所有 SKU 的实际税基；2）评估 OEM 工厂迁至可豁免国家（澳新 / 部分拉美）的可行性；3）"双重 301"叠加申报需 ERP 系统支持；4）等待 USTR 公告豁免名单扩充窗口。
💡 解读分析
USTR 用 Section 301 替代 Section 122 是 2026 关税体系的"结构性节点"——把"全球统一税率"换成"国别差异税率"。对中国跨境卖家的实际含义：1）平均税率小幅上行（11% → 11.2%），但成本分布从"全员轻伤"变为"分国别重伤"；2）"在岸化"逻辑回归，墨西哥、东欧、土耳其、北非的近岸产能将被美方重点豁免；3）10/22 全面合规期倒计时——HS Code + 原产地证明 + 供应链溯源是新三大必备件。

4. 美国 Section 338 三道公告：对加拿大 50% 关税 8/19 生效，含 USMCA 商品

头条 18 天倒计时 Section 338 📅 2026-07-20 签署 · 8/19 生效 · 来源：White House / Baker Botts / Shapiro / Zonos · Baker Botts Tracker · Shapiro 解读
📌 核心事件
7/20 美国总统签署三道 Section 338 公告，以乳制品、酒精饮料、机动车三个加拿大贸易壁垒为由，对数百个税目商品额外征收 50% 从价关税，定于 8/19 美东时间零时生效。这是 Section 338 自 1930 年《关税法》颁布以来首次被援引。
📊 关键数据
税率 +50% 从价；覆盖品类远超乳 / 酒 / 车名义范围，包括水泥、家具、纸张、纺织品、化妆品、运动用品等数百税目；USMCA 优惠内商品亦适用；豁免清单仅含能源、钾肥、Section 232 已覆盖商品（钢铝汽配木材）、关键矿产、鱼；附加 Section 232 铝回岸计划可享优惠；联邦公报及总统公告同步发布。
🌍 影响范围
1）加美贸易关系出现"硬脱钩"信号，连 USMCA 优惠都不再是缓冲；2）北美跨境卖家供应链出现"墨西哥最后一程"需求集中爆发；3）加元短期承压，加拿大消费品 / 工业品出口商利润被压缩；4）中国跨境卖家需重新审视"经加拿大仓转运美国"路径的有效性。
⏭️ 后续动作
1）加美贸易相关的跨境仓 / 转口链路需在 8/19 前完成方案切换；2）USMCA 原产地证书审核加严，墨西哥原产证明成为刚需；3）跨境物流商在 7/15-8/15 出现"加拿大仓抛货 / 墨西哥仓抢位"双向流动；4）加拿大卖家加速 TikTok Shop / Temu 北美跨境布局作为对冲。
💡 解读分析
Section 338 50% 关税是 2026 北美贸易的"分水岭事件"——表面是贸易摩擦升级，本质是美方把"国家安全 / 经济安全"工具箱用到传统盟友身上。给跨境卖家的关键启示：1）"USMCA 缓冲"被证伪，"原产于加"不再是安全标签；2）墨西哥最后一程（最后一公里组装 + 包装）是 2026 下半年最被低估的供应链重构机会；3）"中转加 / 直邮美"路径接近失效，海外仓选址要把"原产地规则"作为首要变量。

5. EU €3 小包关税满月观察：跨境直邮申报"按行计费"成最大合规摩擦点

满月观察 欧盟合规 VAT/IOSS 📅 2026-07-01 生效 · 来源：欧盟委员会 / VATAi / Digital Applied · VATAi 解读 · Digital Applied 解读
📌 核心事件
欧盟废除 €150 以下小包免税政策、Council Regulation (EU) 2026/382 过渡期临时征收 €3 / 申报行关税已生效满月。Commission Implementing Regulation (EU) 2026/1200 与欧盟委员会 6/8 合并指南落地，€3 征收"按申报行"计算（每 H7 关税编码行 €3）。
📊 关键数据
税率：每 H7 申报行 €3（不是按包裹）；覆盖 ≤ €150 intrinsic value 的距离销售商品；覆盖范围包含此前免税的酒精、香水、烟草；过渡期至 2028/7/1；适用 VAT 方案包括 IOSS / Special Arrangements / 标准进口 VAT（皆需缴纳 €3）；2026/11/1 起强制产品标识符 + HS + 原产地；商户默认承担 €3 法律债务。
🌍 影响范围
1）混合 SKU 包裹（多品类多 H7）成本陡升——3 件不同品类 = €9 关税；2）长尾小卖家申报逻辑与拼多多跨境直邮模式面临合规摩擦；3）平台型卖家（Temu / Shein）需统一代征代缴；4）2028/7/1 后将切换为"按品类标准税率"完全体，长期合规要求更严。
⏭️ 后续动作
1）跨境卖家立即梳理 SKU 级 H7 编码映射；2）合并 H7 同类商品打包发货以最小化 €3 计费行；3）评估是否在 EU 海外仓提前备货以切换到"整批进口 + 标准清关"路径；4）11/1 前完成产品标识符 / HS / 原产地数据全字段治理。
💡 解读分析
EU €3 关税不是"小钱"而是"申报逻辑革命"——把"按包裹"变为"按 H7 申报行"。跨境电商的定价模型 / 打包策略 / 物流路径选择都要重写。满月观察的关键洞察：1）"€3 不可怕，可怕的是 €3 × N 个 H7"，SKU 数据治理成为 2026 下半年跨境必修课；2）2028/7/1 完全体落地前，"按 H7 拼单 + EU 海外仓"是双轨最优解；3）欧盟正在把 VAT 改革 / 海关改革 / DSA 数字服务法三线并行推进，跨境平台合规边际成本将持续抬升。

6. 巴西 25% Section 301 关税 7/22 生效：USTR 报复性反击拉美最大经济体

拉美承压 Section 301 新兴市场 📅 2026-07-16 公告 · 7/22 生效 · 来源：USTR / Shapiro / Baker Botts · Shapiro 解读 · ShipperHQ 解读
📌 核心事件
USTR 7/16 宣布对绝大多数巴西进口商品加征 25% Section 301 关税，7/22 美东零时生效，进口商需使用新的 HTSUS 9903.05.01 税目申报。这是 2026 美国对拉美最大经济体的单边关税动作。
📊 关键数据
税率 +25% Section 301；HTSUS 9903.05.01 强制申报；覆盖"绝大多数"巴西进口商品；巴西对美平均税率上行至约 18%，与中国（~27%）形成"新兴市场双高"格局；与既有 MFN / Section 232 / 60 国 Section 301 可叠加。
🌍 影响范围
1）Mercado Libre 美洲跨境卖家：B2C 直邮美国路径成本抬升；2）中国 → 巴西 / 巴西 → 美国双向跨境链路均受影响；3）拉美航空货代需求短期承压，但加速"墨西哥转运"替代方案热度；4）巴西农产品（咖啡、橙汁、肉类）对美出口竞争力下降，反向利好巴西本土加工与对欧出口。
⏭️ 后续动作
1）拉美跨境卖家在 7/22 起需新增 9903.05.01 税目；2）评估巴西仓切换墨西哥仓的可行性；3）巴西本土清关代理 / 物流商需求 Q3 上升；4）Mercado Libre 美洲站点需关注平台是否承担部分关税。
💡 解读分析
巴西 25% Section 301 与 60 国 10-12.5% 同步落地，标志着美方"对拉美政策"的强硬转向。对中国跨境卖家的实际含义：1）"巴西中转美国"路径成本上升，墨西哥成为新的"最后一程"枢纽；2）拉美本土消费市场（Mercado Libre / 美客多）反而被强化为长期战略要地；3）"国别分散 + 海外仓本地化"是 2026 下半年跨境供应链布局的核心命题。

7. 印尼 Sapa UMKM 6/17 减费生效：跨境卖家被排除，本土小微企业享 50% 佣金减免

东南亚挤压 Sapa UMKM Shopee/TikTok Shop/Lazada 📅 2026-06-17 生效 · 来源：印尼合作社与中小企业部 / Bisnis · Tech in Asia · Moca Tech 解读 · Digital in Asia
📌 核心事件
印尼政府 6/17 落地 Sapa UMKM 平台费减半政策，通过认证的本土小微企业（销售本土商品）在 Shopee / TikTok Shop / Lazada 享 50% 佣金减免。明确条款：跨境身份卖家（含部分进口商品）无论订单量均不享受减费。
📊 关键数据
Sapa UMKM 减免幅度 50% 平台佣金；覆盖 Shopee / TikTok Shop / Lazada 三平台；跨境身份（含进口商品 SKU）一律排除；TikTok Shop Seller University 7/1 起新卖家 NFC 身份验证强制；Shopee 同步 2 月起对新加坡 / 马来 / 泰国 / 越南加征 5% 技术服务费；Lazada 保持基础 3.99% 最低费率，主打品牌跨境定位。
🌍 影响范围

⏭️ 后续动作
1）评估在印尼成立本土公司 + 注册 Sapa UMKM 资格的可行性；2）调整 SKU 组合提升本土商品占比；3）Q4 前完成 Shopee 海外仓头程降本（菲律宾 / 马来 / 泰国海运红利窗口）；4）关注 TikTok Shop 7/1 起 NFC 验证要求，避免账户被冻结。
💡 解读分析
印尼 Sapa UMKM 是 2026 东南亚"国别保护"政策密集化的代表。给中国跨境卖家的关键启示：1）"跨境直邮 = 低价 = 红利"模型在多国被同步挤压，本地化是必答题；2）海外仓 + 本土公司 + 税务登记三件套是 2026 下半年东南亚合规入场券；3）平台费率分化（Shopee 让利头程 vs Lazada 上调佣金）反映战略定位差异，卖家需按"中大件 vs 品牌 vs 流量"做平台再分配。
