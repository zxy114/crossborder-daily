关键数据：拟发行不超 3.416 亿股；目标估值 400-500 亿美元（vs 2023 年私募 660 亿）；覆盖 150+ 国家；广州 / 番禺为核心供应链

法国跟进欧盟"3 欧元"政策：欧洲对华跨境电商形成"欧盟统一关税 + 成员国单边监管"双层防御

腾讯源 大橘财经 张志峰 / 吕栋 · 2026-07-11 国际视角 欧盟海关 / 法国海关

继 7 月 1 日欧盟取消 150 欧元以下小额包裹关税豁免、按 HS 税则子目每件征收 3 欧元固定关税后，法国在首周推出针对中国跨境电商的独立监管工具——除欧盟统一关税外，法国海关拟对直邮小包裹加征额外"通关处理费"与目的地国增值税专项审计。欧洲地缘保护主义形成"欧盟统一动作 + 成员国单边加码"双层监管架构，主要针对 SHEIN、Temu、速卖通等中国平台。

核心事件：法国在欧盟 3 欧元统一关税基础上推出独立监管工具；欧洲对中国跨境电商形成"双层监管"
关键数据：欧盟每件固定关税 3 欧元；按 HS 税则子目分项叠加；同一包裹多类别叠加；法国海关推出额外"通关处理费" + 增值税专项审计
影响范围：SHEIN / Temu / 速卖通等中国跨境平台；法国本地零售与物流业；广州 / 杭州 / 义乌产业带；亚马逊欧洲站卖家；跨境支付与海外仓企业
后续动作：关注法国细则落地；评估"法国仓 + 西班牙仓 + 波兰仓"扩建节奏；跟踪欧盟两年过渡期后正式海关改革（拟废除 150 欧元阈值）；Temu 欧洲半托管 / 全托管模式切换
解读："3 欧元"是欧盟放弃 1990 年代以来低值包裹便利化传统的标志性政策，本质是"以海关财政 + 市场监管 + 本地零售保护"三位一体的对华贸易防御机制；法国加码意味着"欧盟统一关税 + 成员国单边"双层防御已成趋势——下一个跟进者很可能是意大利、波兰（已对 Temu 反垄断立案）；对中国卖家而言，单件小包直邮模式不可逆地走完历史，进入"本地化建仓 + 品牌化升级 + 合规化经营"新阶段。

核心事件：Temu / SHEIN 拉美扩张遭遇"合规 + 物流 + 支付"三信号逆风；"local-to-local"模型在拉美面临最严考验
关键数据：巴西 50 美元以下跨境包裹须 CPF + 数字发票；墨西哥 SHEIN × Estafeta 合作解除；阿根廷 Temu 复购率月环比 -18%

后续动作：跟踪 SHEIN 港股 IPO 后拉美募资用途；评估 Temu 阿根廷比索本币结算可能性；墨西哥新物流合作方（可能与 Mercado Libre Envíos 直接合作）；巴西圣保罗 / 墨西哥城海外仓扩容
解读：拉美曾被视为 SHEIN / Temu 继东南亚后的第二增长曲线，但"local-to-local"模型在拉美遇到"基础设施差异 + 货币波动 + 税务复杂性"三大结构性挑战——与欧盟"通过本地仓可绕开"截然不同；这意味着 SHEIN 港股 IPO 募资投向拉美将面临"高投入 + 慢回报"压力，可能倒逼平台转向"巴西本地建厂 + 阿根廷比索定价 + 墨西哥与 Mercado Libre 合资"等更激进的本地化路径。

Temu / SHEIN 通过欧洲本地仓"前置发货"规避 3 欧元关税：从直邮切换到"本仓发货"成主流应对

国际源 The Loadstar / logos-pres.md / swiatcyfrowy.pl · 2026-07-10 腾讯源 罗戈网 / 跨境派 欧洲仓观察

The Loadstar 实地调研发现，欧盟 3 欧元关税生效仅 10 天，Temu 与 SHEIN 已系统性将低值 SKU 切换到"欧洲本地仓发货 + 一件代发"模式，规避跨境直邮关税。具体路径：①SHEIN 在波兰华沙、捷克布拉格、西班牙马德里扩建前置仓；②Temu 通过德国、意大利本地仓为欧洲订单出货；③原本"广州直邮 7-12 天"切换为"欧洲本地仓 1-3 天"。smec 分析师估算，3 欧元/件税对 30 欧元客单价订单相当于 10% 隐性涨价，被本地仓履约成本节约的 15-20% 对冲后，Temu / SHEIN 净成本仍下降。

核心事件：Temu / SHEIN 通过欧洲本地仓前置发货规避 3 欧元关税；"本仓发货"取代"广州直邮"成主流
关键数据：3 欧元关税 ≈ 30 欧元客单价订单的 10% 隐性涨价；本地仓履约成本节约 15-20%；订单时效从 7-12 天缩短至 1-3 天；SHEIN 波兰 / 捷克 / 西班牙 + Temu 德国 / 意大利本地仓
影响范围：中国跨境物流专线货代（业务下滑）；欧洲第三方海外仓（需求暴涨）；波兰 / 捷克 / 西班牙本地仓建仓与租赁；亚马逊 FBA 欧洲仓竞争；广州 / 义乌直邮产业带转型
后续动作：关注波兰 / 捷克 / 西班牙 / 意大利海外仓 Q3-Q4 租金走势；评估"半托管 + 全托管"切换覆盖节奏；本地化品牌投放预算；欧盟 CBAM（碳关税）对本地仓物流的二次影响
解读："本仓发货"是中国跨境电商对欧盟 3 欧元政策的"市场原力式"回应——它把"关税成本 + 物流时效 + 用户体验"三个维度一次性重构：表面看是规避关税，本质是"中国供应链 + 欧洲仓储 + 欧洲履约"的全球化 2.0 模式；这也意味着，过去十年"广州 → 欧美消费者"的小包裹直邮黄金期正式终结，"本地仓 + 本地配送 + 本地品牌"的下一阶段开启。

3 欧元关税冲击波：Temu 削减欧洲广告投放、SHEIN 加速欧洲本地仓"半退出"中国直邮

国际源 PPC Land / smec 分析 / Reuters 引述 · 2026-07-12 腾讯源 中国经营报 李立 一线调研

PPC Land 联合 smec 跨境电商监测平台发布数据：3 欧元关税生效后 10 天内，Temu 在欧洲核心市场（德、法、意、西）Facebook / Google 广告投放量周环比下降 22%，原因是大盘客单价上行后 ROI 模型重置；同时 SHEIN 在欧洲的"半托管 + 全托管"卖家招商速度显著放缓，部分中国直邮卖家被建议主动退出或转向本地仓发货。中国经营报一线调研印证，"低毛利 SKU 主动退出 + 高毛利品牌型 SKU 补位"的供给侧结构出清已启动。

核心事件：3 欧元关税冲击波显现：Temu 欧洲广告投放周环比 -22%；SHEIN 加速卖家本地仓"半退出"；供给侧结构出清启动
关键数据：Temu 欧洲广告投放周环比 -22%；SHEIN 卖家招商速度放缓；低毛利 SKU（<15 欧元）主动退出；高毛利品牌型 SKU 补位
影响范围：Temu / SHEIN 中国卖家结构；Facebook / Google / TikTok 欧洲电商广告大盘；广州 / 义乌直邮产业带（低毛利卖家出清）；欧洲海外仓与本地配送；亚马逊欧洲站卖家
后续动作：跟踪 Q3-Q4 Temu / SHEIN 欧洲 GMV 走势；评估广告投放下降对平台流量与复购的中长期影响；低毛利卖家转向第三方平台（亚马逊、Allegro、Cdiscount）节奏；欧盟两年过渡期后正式海关改革
解读：Temu 欧洲广告投放下降 22% 是一个非常强烈的"市场情绪信号"——它意味着平台判断短期 ROI 已被关税侵蚀，倾向于"控规模 + 保利润"而非"抢市场 + 烧补贴"；这与 SHEIN 港股 IPO 时点高度协同（IPO 前需稳定盈利与现金流），也意味着 Temu 在欧洲的"狂飙突进"阶段暂告段落，进入"控费提质"新节奏。
