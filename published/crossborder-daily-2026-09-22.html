欧盟海关新规正式生效，跨境电商低值包裹进入收费时代
政策监管
来源: KPMG / 欧盟委员会
核心事件 欧盟新《海关法典》于9月20日正式生效，标志着欧盟海关体系重大改革落地。非欧盟平台及卖家被明确为"责任进口商"，直邮小包必须申报数据并担保税款。此前维持多年的150欧元低值包裹免税额度已被取消。
关键数据 自2026年7月1日起，低值包裹临时征收3欧元固定关税；2028年7月起恢复常规关税。2026年11月起，欧盟将对小包裹征收统一处理费，具体金额待欧盟委员会授权法案确定。新规给予成员国12个月过渡期全面实施。
影响范围 所有通过直邮小包进入欧盟的跨境电商卖家、物流服务商及海外仓运营商均受影响，尤其对FBM自发货模式构成直接成本压力。亚马逊、TikTok Shop、速卖通等平台上的非欧盟卖家需立即调整合规架构。
后续动作 卖家需在欧盟境内设立实体或指定授权代表；重新核算含关税的定价模型；评估海外仓或FBA方案以对冲成本；密切关注各成员国执行细则及处理费标准出台进度。
解读分析 此次改革本质上是欧盟将跨境电商进口的监管责任前移，从"边境征税"转向"源头管控"。3欧元固定关税虽绝对值不高，但叠加处理费后将显著压缩低价商品利润空间，预计将加速行业出清，推动供应链向合规化、本土化转型。
美国海关启动国际邮件电子报关测试，de minimis规则持续收紧
政策监管
来源: Avalara / Carra Globe
核心事件 美国海关与边境保护局（CBP）于9月22日正式启动Entry Type 13自愿电子测试，针对价值2500美元以下的国际邮件 shipment 试行新的电子报关流程，替代原有的邮政渠道入境程序。
关键数据 该测试将无限期持续，覆盖所有此前符合de minimis免税待遇的小额包裹。根据现行法律，de minimis豁免将于2027年7月1日依据《One Big Beautiful Bill Act》被永久取消，在此之前CBP正在加紧建立替代性合规框架。
影响范围 所有通过邮政渠道向美国消费者发送低价值商品的跨境电商卖家、转运商及邮政运营商。此前依赖800美元以下免税额度进行低成本入境的中小卖家将受到直接冲击。
后续动作 卖家需评估Entry Type 13电子申报的操作可行性；提前准备10位HTSUS编码、商业发票及原产地证明；对于PGA监管商品、第98/99章货物及自贸区关税减免申请，CBP已将强制执行日期推迟至10月22日，需利用该窗口期完成供应链审计。
解读分析 美国正在系统性地拆除小额包裹免税通道，从Executive Order 14411到Entry Type 13测试，再到 statutory cancellation，三层机制叠加意味着"免税时代"已进入倒计时。2026年Q3将成为跨境卖家合规转型的关键窗口期。
CBP发布CAPE Phase 3部署计划，IEEPA关税退款流程全面数字化
政策监管
来源: JD Supra / ArentFox Schiff
核心事件 CBP贸易项目执行主任Brandon Lord向国际贸易法院提交声明，确认CAPE（综合入境处理系统）第三阶段将于10月6日部署，专门处理已进入最终清算且法院下令重新清算的IEEPA关税退款申请。
关键数据 CAPE Phase 1于2026年4月20日上线，Phase 3将扩展至法院裁定的重新清算案件。新系统允许原始进口商及报关行在线提交退款请求，替代此前的人工处理流程。
影响范围 所有曾缴纳IEEPA关税且已获CIT重新清算令的进口商、贸易律师及报关行。Phase 3上线后，退款申请周期预计将从数月缩短至数周。
后续动作 进口商应核查是否存在符合重新清算条件的未退税款；在10月6日前完成ACE系统账号及CAPE功能权限配置；准备原进口记录及CIT裁决书电子档。
解读分析 CAPE Phase 3是特朗普第二任期内贸易执法与救济体系数字化的标志性进展。系统上线后，IEEPA关税退款的透明度与可预测性将大幅提升，但也意味着CBP对关税征收的追溯能力同步增强，进口商需更谨慎地评估原产地声明及估价合规性。
TikTok Shop东南亚9.9大促GMV翻倍，直播电商持续爆发
平台动态
来源: 易仓ERP
核心事件 TikTok Shop东南亚9.9大促收官，GMV达去年同期1.9倍，累计超130万跨境商家及联盟直播间参与，9月9日单日直播观看量突破1.8亿次，短视频累计播放量达14.6亿次，单日短视频带货GMV同比增长80%。
关键数据 GMV同比增速接近100%，直播观看量达1.8亿次，短视频播放量14.6亿次。这些数据表明东南亚市场内容电商模式已进入规模化增长阶段。
影响范围 所有布局TikTok Shop东南亚站的跨境卖家、MCN机构、物流服务商。东南亚年终旺季（11.11、12.12）的竞争烈度将显著提升。
后续动作 卖家应立即启动年终旺季备货计划；加大达人合作与内容制作投入；优化直播供应链及物流时效；提前锁定11.11及12.12大促的流量预算与库存。
解读分析 TikTok Shop在东南亚的成功验证了"内容电商"在亚太新兴市场的爆发力。1.9倍GMV增长背后是平台算法迭代、本地卖家生态成熟及消费者行为改变的共振。对中国跨境卖家而言，东南亚正从"试水市场"升级为"必争之地"。
WTO举办首届世界贸易与技术日，AI与贸易融合成为核心议题
行业趋势
来源: tralac / WTO
核心事件 世界贸易组织于9月14日在日内瓦举办首届"世界贸易与技术日"，数百名参与者齐聚探讨AI如何根本性地改变跨境 Commerce 的演进路径。WTO总干事Ngozi Okonjo-Iweala指出，AI正在降低贸易成本并提升服务业生产力。
关键数据 去年全球货物贸易量增长4.6%，其中约42%的增量来自AI相关产品贸易。AI被视为贯穿跨境数据流、关键矿产等贸易 backbone 的核心变量。
影响范围 跨境电商卖家、AI技术服务商、物流科技公司、政策制定者。AI与贸易规则的交叉地带将成为未来3-5年的监管焦点。
后续动作 关注WTO关于AI与贸易规则的后续报告；评估AI在选品、客服、合规等环节的应用潜力；跟踪各国对AI生成内容、数据跨境流动的监管动态。
解读分析 WTO首次将AI设为顶级会议主题，释放明确信号：贸易政策制定者已意识到AI对全球贸易格局的重塑作用。对于跨境电商行业，这意味着AI驱动的效率提升将不再是"可选项"，而是参与全球竞争的"基础设施"。
美联储时隔三年首次加息25基点，跨境资金成本上升
宏观经济
来源: SuperBrowser / 紫鸟浏览器
核心事件 美联储于9月17日凌晨宣布加息25个基点，联邦基金利率目标区间调整至3.75%-4%，为三年来首次加息。主席沃什强调通胀"太高持续太久了"，特朗普公开表达不满。
关键数据 利率从3.50%-3.75%上调至3.75%-4.00%，加息幅度为25个基点。市场对年内是否还有一次加息存在分歧，美元指数短期走强。
影响范围 所有涉及美元结算、海外仓融资、供应链金融的跨境电商企业。融资成本上升将直接影响库存持有成本及现金流管理。
后续动作 卖家应重新评估美元融资及汇率对冲策略；压缩高库存SKU的备货周期；关注美联储11月议息会议对年内再次加息的信号。
解读分析 美联储重启加息周期，标志着全球货币政策环境发生转折。对跨境电商而言，直接冲击在于美元融资成本上升及人民币汇率波动加大，间接影响是全球消费需求可能因信贷收紧而降温，卖家需进入"防御性库存管理"模式。
中美301关税互降方案敲定，约300亿美元商品将受益
贸易政策
来源: SuperBrowser / 紫鸟浏览器
核心事件 中美双方已敲定301关税对等降税方案，针对约300亿美元商品下调额外关税。美方计划于9月24日公布完整降税清单，涵盖特定品类消费品与中间品。
关键数据 降税商品总值约300亿美元，具体品类清单待9月24日公布。这是自2024年以来中美贸易摩擦缓和的最实质性进展。
影响范围 对美出口跨境电商卖家、中美干线物流服务商、海外仓运营商。降税清单覆盖品类中的卖家将直接获得成本优势。
后续动作 卖家应持续关注9月24日美方官方清单发布；提前核算降税对SKU利润率的实际影响；对于清单外仍维持高关税的商品，评估是否启动第三国中转或本土化采购。
解读分析 300亿美元降税规模相对中美全年6000多亿美元贸易额占比有限，但信号意义大于实际金额。若此次降税能落地执行，可能为后续更大范围的关税谈判创造窗口期。跨境电商卖家应保持谨慎乐观，避免因预期降税而过度备货。
巴西大幅放松跨境进口税收，个人海淘迎来政策红利
区域市场
来源: SHOPLINE Japan / 宫内瑞纪
核心事件 巴西政府于9月15日正式颁布新法，大幅放松针对个人消费用途的跨境电子商务进口税收制度，降低个人海淘门槛。这是拉美最大经济体近年来最重大的跨境电商税收改革。
关键数据 具体税率调整幅度及免税额度上限待官方细则公布。巴西跨境网购人群约2350万成年人，其中86.4%为线上购物人群，52.8%为"折扣型消费者"。
影响范围 所有面向巴西市场的跨境平台卖家（Shopee、Mercado Libre、Shein等）、国际物流服务商及支付机构。政策利好将直接刺激巴西消费者对高性价比进口商品的需求。
后续动作 卖家应评估巴西市场的定价空间及物流时效；与本地清关代理确认新规执行细节；针对黑五、圣诞季加大巴西市场投放；关注后续可能出台的平台税收分摊机制。
解读分析 巴西此次税收放松是拉美跨境电商政策的标志性转向。作为区域最大经济体，巴西的开放姿态可能引发阿根廷、智利等国的政策跟进。中国卖家应将巴西视为2026年-2027年最值得布局的新兴增量市场。
全球跨境电子商务规模突破1.2万亿美元，新兴市场成主要引擎
行业数据
来源: Web Tonic / ECDB
核心事件 ECDB最新报告显示，2026年全球跨境电子商务收入达到约1.209万亿美元，较2025年的1.135万亿美元增长6.6%。2023-2026年复合年增长率为7.7%，显著高于同期国内电商增速。
关键数据 跨境购物转化率比 domestic 低约31%，但平均订单价值高44%，退货率低22%。92%的消费者偏好本地货币定价，75%希望使用母语购物。85%的美国买家通过社交媒体接触外国品牌，其中70%发生在Instagram。
影响范围 所有跨境电商从业者，特别是聚焦欧美成熟市场及东南亚、拉美新兴市场的卖家。数据揭示了"体验本土化"对转化率的关键影响。
后续动作 卖家应将本地货币结算、多语言客服、本土化退换货列为最高优先级优化项；针对高AOV品类（如户外装备、家居装饰）加大投放；在Instagram等社交平台加强品牌内容建设。
解读分析 1.2万亿美元的市场规模已使跨境电商从"增量机会"变为"必争之地"。数据的另一面是：跨境购物的转化率瓶颈仍未突破，"语言、物流、支付"三大障碍虽已缓解，但"体验差距"仍是决定胜负的关键变量。2026年的竞争将从"价格战"转向"体验战"。
联合国报告：贸易规则滞后于数字经济，发展中国家面临数字鸿沟加剧风险
行业趋势
来源: UNCTAD
核心事件 联合国贸易和发展会议（UNCTAD）发布9月全球贸易更新报告，指出现有多边服务贸易规则大多建立于数字时代之前，数字贸易条款虽在区域及双边协定中快速扩张，但形成碎片化监管格局，发展中国家参与度不均。
关键数据 2000-2025年签署的优惠贸易协定中，55%包含电子商务或数字贸易条款。2020年以来，90%的发达国家、62%的发展中国家及66%的最不发达国家参与了含此类条款的协定。但最不发达国家服务出口中仅少量可数字化交付。
影响范围 跨境电商行业的长期政策环境。发展中国家卖家可能面临更高的合规成本及市场准入壁垒；发达市场卖家需应对日益复杂的跨境数据流动及数字服务税规则。
后续动作 卖家应关注目标市场的数字贸易协定及数据本地化要求；评估在不同司法管辖区存储及处理数据的合规成本；利用区域协定（如RCEP、CPTPP）中的数字贸易章节降低合规负担。
解读分析 UNCTAD的报告揭示了跨境数字贸易的"制度赤字"——技术进步速度远超规则协同速度。对于跨境电商卖家，这意味着未来3-5年将面临日益碎片化的数字合规环境。能够提前建立全球合规能力的企业，将在下一轮行业洗牌中获得结构性优势。
